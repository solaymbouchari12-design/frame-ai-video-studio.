# Frame AI — مساعد خطة المونتاج

## تشغيل محلي

1. ثبّت Node.js 18 أو أحدث.
2. أنشئ مفتاح API من مزود الذكاء الاصطناعي.
3. عيّن المفتاح كمتغير بيئة **على الخادم فقط**، ولا تضعه في `index.html` أو مستودع عام:
   - macOS/Linux: `export OPENAI_API_KEY="..."`
   - PowerShell: `$env:OPENAI_API_KEY="..."`
4. شغّل: `node server.js`
5. افتح `http://localhost:3000`، واكتب وصف المشروع ثم اضغط «إنشاء خطة مونتاج بالذكاء الاصطناعي».

اختياري: عيّن `OPENAI_MODEL` لاختيار نموذج آخر متاح لحسابك. الافتراضي `gpt-4.1-mini`.

## ما الذي يفعله النموذج الأولي؟

يرسل وصف المشروع ومواصفاته إلى الخادم؛ يعيد الخادم خطة مشاهد عربية (توقيت تقريبي، صورة، نص شاشة وتعليق صوتي مقترح). لا يقوم هذا النموذج الأولي برندر أو تصدير ملف فيديو، ولا يرفع الفيديو الموجود إلى مزود الذكاء الاصطناعي.

## قبل النشر الفعلي

- أضف تسجيل دخول آمن عبر الخادم وقاعدة بيانات؛ تسجيل الدخول الحالي تجريبي ومحلي.
- لا تحفظ كلمات المرور أو الطلبات في `localStorage` للإنتاج.
- أضف تخزين ملفات خاصاً وروابط رفع مؤقتة، حدود حجم، فحص ملفات، وموافقة المستخدم قبل إرسال أي مادة لطرف خارجي.
- أضف طابور مهام وحالة تقدم؛ لا تشغّل مهام فيديو طويلة داخل طلب HTTP عادي.
- أضف أدوات تنفيذ فعلية مثل FFmpeg/Remotion أو مزود توليد فيديو، ومراجعة بشرية قبل تسليم النتائج.
- أضف حدود استخدام ومصادقة وحماية من الإساءة وتكاليف API.
